# Text File Statistics Analyzer

Небольшое настольное приложение на Python для анализа TXT-файлов. Оно подсчитывает основные показатели текста, показывает результат в графическом окне и консоли, а при необходимости сохраняет отчёт в отдельный файл.

## Возможности

- выбор текстового файла через диалоговое окно;
- чтение файлов в UTF-8, UTF-8 с BOM и CP1251;
- просмотр полной статистики или отдельного показателя;
- подсчёт символов, строк, слов и уникальных слов;
- вывод до 10 наиболее частых слов;
- вывод результата в окне приложения и в консоли;
- сохранение выбранного отчёта в TXT в кодировке UTF-8;
- показ сообщений об ошибках чтения и сохранения файлов.

## Требования

- Windows;
- Python 3.10 или новее;
- доступный модуль `tkinter`.

Сторонние Python-пакеты не нужны. `tkinter`, `re`, `collections` и `pathlib` входят в стандартную библиотеку Python. В стандартной установке Python для Windows `tkinter` обычно доступен.

Чтобы проверить наличие `tkinter`, откройте PowerShell или командную строку в папке проекта и выполните:

```powershell
python -m tkinter
```

Должно открыться демонстрационное окно Tk.

## Запуск

Откройте терминал в папке, где находится `text_analyzer.py`, и выполните:

```powershell
python text_analyzer.py
```

Если команда `python` не распознаётся, попробуйте лаунчер Windows:

```powershell
py text_analyzer.py
```

## Использование

1. Нажмите **«Выбрать файл»** и выберите TXT-файл.
2. Программа покажет полную статистику. Чтобы увидеть отдельный показатель, выберите его в списке: **«Символы»**, **«Строки»**, **«Слова»** или **«Частые слова»**.
3. Результат отображается в окне и печатается в консоль.
4. Нажмите **«Сохранить отчёт»**, выберите папку и имя файла. По умолчанию отчёт называется `<имя_исходного_файла>_статистика.txt`.

## Подсчёт статистики

- **Символы** — длина прочитанного текста, включая пробелы и переводы строк после стандартной обработки Python.
- **Строки** — число строк, определяемое методом `splitlines()`.
- **Слова** — последовательности русских или английских букв и цифр. Регистр не учитывается, знаки пунктуации разделяют слова.
- **Уникальные слова** — число разных слов после приведения к нижнему регистру.
- **Частые слова** — до 10 слов с наибольшей частотой.

## Кодировки и ошибки

Функция `read_text_file()` последовательно пробует `utf-8-sig`, `utf-8` и `cp1251`. Если кодировка не подходит, программа переходит к следующей. Ошибки доступа к файлу или декодирования отображаются в окне приложения.

Поддерживаются только перечисленные кодировки. Слова распознаются только на русском и английском языках; текст на других языках может учитываться не полностью.

## Структура проекта

```text
text_analyzer.py                  # Исходный код приложения
test_text.txt                     # Пример текстового файла
Отчет по итоговому проекту.docx   # Отчёт по проекту
Отчет по итоговому проекту.pdf    # Отчёт в PDF
README.md                         # Описание и инструкция по запуску
```

## Основные части кода

- `read_text_file(file_path)` — читает файл в одной из поддерживаемых кодировок.
- `analyze_text(text, statistic_type)` — считает выбранные показатели и формирует текст отчёта.
- `TextAnalyzerApp` — создаёт окно приложения и обрабатывает выбор файла, вывод статистики и сохранение отчёта.
- `main()` — запускает графический интерфейс.

## Проверочные примеры

Для текста `Привет мир\nПривет` ожидаются 17 символов, 2 строки, 3 слова, 2 уникальных слова и частота слова `привет`, равная 2. Для пустого текста счётчики равны нулю, а вместо списка частых слов выводится сообщение об отсутствии слов. Чтение примеров UTF-8 с BOM и CP1251 также проверялось.
